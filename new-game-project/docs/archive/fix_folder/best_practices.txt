# Fire Emblem Tactical RPG - Best Practices & Coding Standards

**Project**: Fire Emblem-style Tactical RPG  
**Engine**: Godot 4.x  
**Language**: GDScript  
**Status**: Production-Ready Codebase

---

## 🎯 **Project-Specific Best Practices**

### 1. **Type Safety (100% Required)**

**Mandatory**: All code must use strict static typing.

✅ **Correct**:
```gdscript
var unit_manager: UnitManager = null
var grid_position: Vector2i = Vector2i.ZERO
var deployed_units: Array[Unit] = []
var bond_data: Dictionary = {}

func calculate_damage(attacker: Node, defender: Node) -> int:
    return 0
```

❌ **Incorrect**:
```gdscript
var unit_manager = null  # Missing type
var grid_position  # Missing type
var deployed_units = []  # Missing Array type
```

**Benefits**:
- 10-30% performance improvement
- Compile-time error detection
- Better IDE autocomplete
- Prevents runtime type errors

---

### 2. **Resource System (Data-Driven Design)**

All game data must use typed Resources, not Dictionaries.

✅ **Correct**:
```gdscript
class_name CharacterData
extends Resource

@export var character_id: String = ""
@export var character_name: String = ""
@export var primary_class: CharacterClass
```

**Current Resources**:
- `CharacterData` - Character stats and progression
- `CharacterClass` - Class definitions
- `Weapon` - Weapon properties
- `SupportConversation` - Dialogue data
- `WorldMapNode` - Campaign nodes
- `MapData` - Map information
- `Skill` - Skill definitions

---

### 3. **Dependency Injection (No Hardcoded Paths)**

❌ **Never do this**:
```gdscript
var bond_system = get_node("/root/Main/GameManager/BondSystem")
```

✅ **Do this**:
```gdscript
var bond_system: BondSystem = null

func set_dependencies(bs: BondSystem) -> void:
    bond_system = bs
```

**Pattern**:
1. Declare dependencies as typed variables
2. Provide `set_dependencies()` method
3. Parent/manager injects dependencies
4. Validate in `_ready()`

---

### 4. **Signal-Based Communication**

**Never** use direct node access for cross-system communication.

✅ **Correct**:
```gdscript
# In Unit
signal unit_died(unit: Unit)

func _on_death() -> void:
    unit_died.emit(self)

# In Manager
func _ready() -> void:
    unit.unit_died.connect(_on_unit_died)
```

**Project Signals**:
- `SignalBus.unit_health_changed`
- `SignalBus.unit_died`
- `SignalBus.phase_changed`
- `support_unlocked(char_a, char_b, rank)`
- `bond_updated(partner_id, new_rank)`

### 5. **Error Handling (100% Coverage)**

Every function must validate inputs and handle errors.

✅ **Correct**:
```gdscript
func setup(characters: Array[CharacterData], spawns: Array[Vector2i]) -> void:
    # Validate inputs
    if characters.is_empty():
        push_error("UnitSelectionPanel: No characters provided")
        return
    
    if spawns.is_empty():
        push_warning("UnitSelectionPanel: No spawn positions")
    
    # Null checks
    if not character:
        push_error("Null character in _show_details")
        return
    
    # Method existence
    if not viewer.has_method("setup"):
        push_error("Viewer missing setup() method")
        viewer.queue_free()
        return
```

**Required Checks**:
- Empty arrays/strings
- Null references
- Method existence (`has_method()`)
- Signal existence (`has_signal()`)
- Scene load failures
- Index bounds

### 6. **Performance: Dirty Flags**

Never update visuals every frame. Use dirty flags.

✅ **Correct**:
```gdscript
var _state_dirty: bool = false

var state: TileState:
    set(value):
        if state != value:
            state = value
            _state_dirty = true

func _process(_delta: float) -> void:
    if _state_dirty:
        _update_visual_state()
        _state_dirty = false
```

**Applied to**:
- TacticsTile visual updates
- HP bar updates
- UI refresh cycles

---

### 7. **Memory Management**

**Always clean up resources:**

```gdscript
var selection_tween: Tween = null

func select() -> void:
    # Kill old tween
    if selection_tween and selection_tween.is_valid():
        selection_tween.kill()
    
    # Create new
    selection_tween = create_tween()
    # ... setup tween

func _exit_tree() -> void:
    # Cleanup on removal
    if selection_tween and selection_tween.is_valid():
        selection_tween.kill()
        selection_tween = null
```

**Critical for**:
- Tweens
- Timers
- Signals (though auto-disconnected)
- Dynamically loaded scenes

---

### 8. **Scene vs. Script Decision**

**Use Scenes (.tscn) for**:
- UI panels (PrepScreen, SupportViewer)
- Units (Unit, DuoUnit, SoloUnit)
- Visual effects
- Prefabs/templates

**Use Scripts (.gd) for**:
- Managers (UnitManager, PhaseManager)
- Resources (CharacterData, Weapon)
- Autoloads (GridManager, SignalBus)
- Pure logic classes

---

### 9. **Autoloads (Minimal Use)**

**Current Autoloads** (Keep minimal):
- `GridManager` - Grid system (truly global)
- `SignalBus` - Event system
- `GameConfig` - Configuration
- `DebugLog` - Logging utility

**Do NOT use Autoloads for**:
- Game state (use GameStateManager node)
- Level-specific logic
- Managers that belong to Main scene

### 11. **Naming Conventions**

**Strictly Enforce**:

| Type | Convention | Example |
|------|------------|---------|
| Classes | PascalCase | `CharacterData`, `BondSystem` |
| Files | snake_case | `character_data.gd`, `unit_manager.gd` |
| Variables | snake_case | `bond_points`, `current_health` |
| Constants | UPPER_SNAKE | `POINTS_FOR_C`, `MAX_LEVEL` |
| Functions | snake_case | `calculate_damage()`, `_on_ready()` |
| Signals | snake_case | `unit_died`, `support_unlocked` |
| Enums | PascalCase | `BondRank`, `TileState` |
| Enum Values | UPPER_SNAKE | `NONE`, `C_RANK`, `HOVERING` |

### 12. **Documentation Standards**

Every file must have:

```gdscript
class_name BondSystem
extends Node
## Manages bond/support relationships between characters
##
## Tracks bond points, unlocks support conversations,
## handles S/A+ exclusivity

## Award bond points between two characters
## @param char_a: First character
## @param char_b: Second character
## @param amount: Points to add
func add_bond_points(char_a: CharacterData, char_b: CharacterData, amount: int) -> void:
```

**Required**:
- Class-level description (`##`)
- Function documentation for public methods
- Parameter descriptions (`@param`)
- Return value description (`@return`)

### 13. **Constants Over Magic Numbers**

❌ **Never**:
```gdscript
if bond_points >= 50:  # What is 50?
    unlock_c_rank()
```

✅ **Always**:
```gdscript
const POINTS_FOR_C: int = 50
const POINTS_FOR_B: int = 150
const POINTS_FOR_A: int = 300

if bond_points >= POINTS_FOR_C:
    unlock_c_rank()
```

**All constants** should be in `GameConfig` or class constants.

### 14. **Serialization (Save/Load)**

Every persistent object must implement:

```gdscript
## Serialize to save data
## @return: Dictionary of save data
func serialize() -> Dictionary:
    return {
        "character_id": character_id,
        "current_level": get_current_level(),
        "bond_data": bond_data.duplicate()
    }

## Deserialize from save data
## @param data: Save data dictionary
## @return: true if successful
func deserialize(data: Dictionary) -> bool:
    if not data:
        return false
    
    character_id = data.get("character_id", "")
    # ... restore state
    return true
```

**Current Systems with Save/Load**:
- CharacterData
- WeaponInventory
- WorldMap
- BondSystem (via CharacterData)
